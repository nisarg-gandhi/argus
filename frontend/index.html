    Reading the narratives

    Deciding who is the same person

    A shared phone, IMEI, vehicle or bank account is strong evidence. Names are weak evidence, weighted down when the surname is common. Every scored pair lands in one of three bands, and anything unclear comes to you.

    Evidence chain

    Three agencies each keep their own copy of every audit record. Entries are signed by the officer who made them, blocks are Merkle-sealed and endorsed by every agency. Altering one copy is caught, and the other two out-vote it.

    Try to tamper with it

    These commands edit a node's database file directly, the way an insider with disk access would. The app is not involved. Watch the seal at the top of this page.

    # in backend/, with the server still running
python -m app.chain.tamper --node forensic_lab            # change one record
python -m app.chain.tamper --node court_registry --rehash # change it and recompute every hash
python -m app.chain.verify                                # independent audit, no server needed
python -m app.chain.verify --evidence bundle.json         # prove an exported bundle is authentic
